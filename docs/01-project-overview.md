# Project Overview

## What is Biela Noc?

Biela Noc (White Night / Nuit Blanche) is a contemporary art festival held annually in Slovakia. The event takes place in two cities — **Bratislava (BA)** and **Košice (KE)** — and has run editions from 2020 to 2025. A special edition was also held in **Humenné**.

## What is This Project?

A public-facing website and content management system for the festival. It serves two audiences:

1. **Visitors** — browse artists, view maps, find practical info, buy tickets
2. **Organizers** — manage content (artists, partners, notifications, articles) via an admin panel

## Domain

- Production URL: `bielanoc.sk`
- Admin URL: `admin.bielanoc.sk` (previous setup)

## Key Characteristics

- **Bilingual**: Slovak (primary) + English
- **Multi-city**: content is scoped to Bratislava or Košice
- **Multi-year**: each edition is archived and browsable
- **Content-heavy**: ~22 content types, rich media (images, audio, maps)
- **Event-driven**: push notifications to mobile app users
- **Seasonal traffic**: spikes around festival dates (typically October)
